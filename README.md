# Unit Test 2 study plan (Class 8, ICSE)

An interactive study plan and revision notes page for Unit Test 2 (3 to 14 December 2026).

- **Plan + timer:** 25-minute focus timer and a day-by-day plan with tick boxes
- **Revision notes:** visual notes, flip cards, quick quizzes and links per subject
- **Maths mistake lab:** practice-question generator, anti-silly-mistake routine, mistake log
- **For parents:** how to run sessions and what to double-check

Progress is saved in the browser (localStorage) on the device being used.

Served with GitHub Pages from the `main` branch root.
